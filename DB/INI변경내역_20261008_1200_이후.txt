 1. HOST_TASK  EcsComA.ini  (세 벌 모두 같은 변경)
-----------------------------------------------------------------------

[Property] 구역에 항목 하나를 더했다.

  전)
      [Property]
      RE_DRCT_CNT=3

  후)
      [Property]
      RE_DRCT_CNT=3
      ; P-BOX 입고 요구(L) 전문에 미실행 유무를 붙일지.
      ;   1 = 원본 형식.  L 작업번호#1(4) 미실행#1(1) 작업번호#2(4) 미실행#2(1)  = 11자
      ;   0 = 문서 IV.9.  L 작업번호#1(4) 작업번호#2(4)                          =  9자
      ; 현장에서 도는 ECS 가 11자를 보내므로 기본값은 1 이다.
      BOX_STO_REQ_FLAG=1

  왜 넣었나
      기존 ECS(CHostCl::RequestBoxStore)는 작업번호 뒤마다 그 작업대의
      미실행 유무 한 자리를 더 붙여 11자로 보낸다. 그런데 인터페이스
      문서 [09]Interface목록서 IV.9 에는 그 항목이 없어 9자다.
      현장 상위가 어느 쪽을 읽는지 몰라 고를 수 있게 했다.
      기본값 1 은 현장에서 도는 것(원본)에 맞춘 것이다.

  읽는 곳
      WCS_TASK_HOST/CCliWork.cs  GfIsBoxStoReqFlagUsed()
      INI 는 한 번만 읽고 그 뒤로는 값을 들고 쓴다.

  세 벌을 같이 고친 까닭
      ini/      : 원본
      bin/Debug : 디버그 실행이 실제로 읽는 것
      bin/Release : 릴리스 실행이 읽는 것
      한쪽만 고치면 실행할 때 조용히 옛 설정으로 돈다.

 2. 같이 바로잡은 것 - 파일 맨 앞 BOM
-----------------------------------------------------------------------

위 항목을 넣을 때 쓴 스크립트가 세 파일을 UTF-8 BOM 으로 저장했다.
원래는 BOM 이 없었다.

  전) 5B 57 4D ...   "[WM..."
  후) EF BB BF 5B    BOM + "["      <- 이것이 문제
  다시) 5B 57 4D     원래대로 되돌림

  왜 문제인가
      INI 는 GetPrivateProfileString / GetPrivateProfileInt (ANSI API) 로
      읽는다. 맨 앞에 BOM 이 있으면 첫 줄이 "[WMS]" 가 아니라
      "<BOM>[WMS]" 가 되어 구역 머리로 인식되지 않는다.
      그러면 [WMS] 구역의 INFO 를 못 읽고 빈 값이 된다.

  영향 범위
      modCmLib.cs 의 ReadInitProfile() 두 곳이 [WMS] INFO 를 읽어
      WmsInfo.CWmsInfo.WmsDBInfo(...) 에 넘긴다(DB 접속정보 고르기).
      PostgreSQL 쪽은 [DB] 구역을 따로 읽으므로 지금 돌고 있는 구성에는
      드러나지 않았지만, 두고 보면 안 되는 상태였다.

  지금은 세 파일 모두 BOM 없이 되돌려 두었다.
  다른 INI(WCS_DB.INI, ENV_IOSCH.INI 등)는 처음부터 BOM 이 없다. 확인했다.

 3. 원격지에 올릴 때
-----------------------------------------------------------------------

EcsComA.ini 를 파일째 덮지 말 것.
  [Network] RemoteIP / RemotePort 와 [DB] IP 가 현장 값이다.
  [Property] 구역에 아래 한 줄만 더하면 된다.

      BOX_STO_REQ_FLAG=1

  이 항목이 없어도 코드 기본값이 1 이라 원본 형식(11자)으로 나간다.
  9자로 보내야 할 때만 0 으로 적으면 된다.

메모장으로 고칠 때 "UTF-8" 로 저장하면 BOM 이 붙는다.
  "ANSI" 로 저장할 것. (위 2번과 같은 일이 생긴다)
